## 3. Kolaborasi dan Integrasi

Kedua anggota bekerja menggunakan Git dan GitHub dengan alur kerja berikut:

1. Membuat dan mengerjakan Issue sesuai pembagian tugas.
2. Mengembangkan fitur pada branch masing-masing.
3. Mengirim perubahan melalui Pull Request menuju branch `main`.
4. Melakukan review terhadap pekerjaan anggota lainnya sebelum penggabungan.
5. Melakukan integrasi, pengujian, dan pemeriksaan akhir aplikasi secara bersama.

Integrasi dataset dan aplikasi utama dilakukan melalui [PR #22 – Add 50 Court Decisions Dataset and Main Application](https://github.com/heinsenhan-lab/uts-struktur-data-narkotika-kelompok-17/pull/22).

## 4. Tanggung Jawab Anggota

Setiap anggota bertanggung jawab terhadap pekerjaan yang tercantum pada pembagian kontribusi. Kedua anggota juga bertanggung jawab memahami implementasi, memeriksa hasil pengujian, serta memastikan aplikasi dan dokumentasi sesuai dengan ketentuan tugas UTS.
