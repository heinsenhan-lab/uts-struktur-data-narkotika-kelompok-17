Dokumentasi Sumber Data (Data Provenance)

Sumber Data

Data putusan dalam proyek ini bersumber dari Direktori Putusan Mahkamah Agung Republik Indonesia.

Situs resmi: https://putusan3.mahkamahagung.go.id/

Tujuan Pengumpulan Data

Data dikumpulkan untuk memenuhi kebutuhan aplikasi pengelolaan dan analisis putusan perkara narkotika.

Informasi yang Dicatat

Setiap data putusan diusahakan memiliki informasi berikut:

- Nomor perkara
- Nama pengadilan
- Tanggal putusan
- Kode terdakwa (anonim)
- Jenis narkotika
- Berat barang bukti
- Pasal dakwaan dan pasal terbukti
- Tuntutan dan vonis
- Denda
- Informasi barang bukti

Aturan Validasi Data

1. Setiap putusan harus memiliki sumber yang dapat ditelusuri.
2. Informasi yang tidak tersedia dicatat sebagai nilai kosong atau nilai default sesuai tipe data.
3. Informasi yang tidak ditemukan tidak boleh dibuat berdasarkan perkiraan.
4. Identitas terdakwa dianonimkan menggunakan kode.
5. Setiap catatan harus menyertakan tautan atau identitas sumber putusan.

Pembagian Pengumpulan Data

Pengumpulan data dilakukan oleh kedua anggota kelompok dengan target masing-masing 25 putusan, sehingga total terdapat 50 putusan.

Catatan

Daftar nomor perkara, tautan sumber, dan informasi hasil verifikasi akan dicatat secara terpisah selama proses pengumpulan dataset.
